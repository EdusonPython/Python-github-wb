# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = (ab)/2
- Trapezoid: S = ((a + b)h)/2
- Rhombus: S = (d₁ d₂)/2
- Parallelogram: S = a h

## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c
- Trapezoid: P = a + b + c + d
- Rhombus: P = 4a
- Parallelogram: P = 2a + 2b
